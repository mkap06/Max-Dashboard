# Max Kaplan Bot

A website frame for **Max Kaplan Bot**, a virtual double of Max Kaplan that people can use to interact with Max.

Open `index.html` in a browser to test locally. The same file sits at the repo root so GitHub Pages can serve it.

## Test locally

Open the file directly:

```bash
open index.html
```

Or serve the folder:

```bash
python3 -m http.server 8080
```

Then visit `http://localhost:8080`.

## GitHub Pages

1. Push this repo.
2. In the GitHub repo: Settings → Pages → Deploy from branch `main` / root.
3. The live site will load `index.html`.
